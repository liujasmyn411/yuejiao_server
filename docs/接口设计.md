# 粤教服务 AI Agent 系统 — 接口设计

## 概述

- 框架：FastAPI
- 统一聊天入口：`POST /api/chat`（替代外部路由平台，游客/学生/员工共用）
- 认证方式：JWT Bearer Token（`Authorization: Bearer <token>`）
- 登录接口：`POST /api/login`
- API 文档：`http://localhost:8000/docs`

角色权限：
- 游客（未登录）：仅可访问统一聊天入口（路由到客服 Agent）
- STUDENT：客服 Agent + 学生 Agent + 仅查本人数据
- EMPLOYEE / ADMIN：客服 Agent + 企业 Agent + 企业管理 API

### 健康检查


响应：`{"status": "healthy", "time": "2026-05-17 12:00:00"}`

## 二、统一对话入口

### 智能路由对话

```
POST /api/chat
```

认证：可选（`get_optional_user`，无 token 即为游客）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| message | string | 是 | 用户输入文本 |
| student_id | int | 否 | 学生ID |
| user_id | int | 否 | 用户ID |
| session_id | string | 否 | 会话ID（用于多轮槽位填充） |

路由逻辑：
1. 检查是否有活跃的槽位填充会话 → 继续收集
2. LLM 意图分类（customer / enterprise / student）
3. LLM 不可用时 → 本地关键词兜底
4. 角色权限校验 → 路由到对应 Agent

响应：
```json
{
  "intent": "event_registration",
  "response": "近期有以下活动...",
  "confidence": 0.9,
  "agent": "customer"
}
```

**支持的意图（客服 Agent）：** company_info / business_query / policy_query / project_recommend / event_registration / faq / profile_match / feedback / chitchat

**支持的意图（企业 Agent）：** lead_create / lead_query / lead_update / daily_report / data_query / company_guide / approval / dashboard / lead_profile / chitchat

**支持的意图（学生 Agent）：** admin_service / psych_care / feedback / academic_query / progress_track / life_support / upgrade_intent / data_query / chitchat

## 三、客服接口 `/api/customer`

### 3.1 活动讲座

#### 查询所有活动

```
GET /api/customer/events
```

认证：无需

响应：
```json
{
  "events": [
    {
      "id": 1, "event_name": "2026秋季英国留学申请全攻略",
      "event_type": "线上", "speaker": "王强",
      "start_time": "2026-05-18 19:00:00",
      "location": "腾讯会议：123-456-789",
      "max_participants": 200, "current_participants": 156,
      "event_status": "报名中"
    }
  ]
}
```

#### 活动报名

```
POST /api/customer/events/register
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| event_id | int | 是 | 活动ID |
| customer_id | int | 是 | 客户ID |
| customer_name | string | 否 | 客户姓名 |
| contact | string | 否 | 联系方式 |

业务规则：报名已满时返回 400

#### 查询活动报名列表

```
GET /api/customer/events/{event_id}/registrations
```

---

### 3.2 课程项目

#### 查询项目列表

```
GET /api/customer/projects?category=新加坡-本科
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| category | string | 否 | 按类别筛选 |

---

### 3.3 客户画像研判

#### 画像匹配推荐

```
POST /api/customer/profile-match
```

支持 JSON body 或 query 参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| age | int | 否 | 年龄 |
| education | string | 否 | 学历（初中/高中/大专/本科/硕士等） |
| intended_country | string | 否 | 意向国家 |

响应：
```json
{
  "matches": [
    {
      "project_name": "新加坡国立大学商科硕士",
      "category": "硕士", "country": "新加坡",
      "match_score": 75,
      "match_reasons": ["匹配意向国家：新加坡", "学历匹配：本科"]
    }
  ]
}
```

计分规则：国家匹配 +30 / 学历匹配 +20 / 年龄匹配 +25

---

### 3.4 文件解析（客户意向研判）

```
POST /api/customer/parse-file
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | UploadFile | 是 | PDF / Excel / TXT |
| owner_employee_id | int | 否 | 归属员工ID |

流程：解析文件 → 提取画像 → 研判意向 → 符合条件的自动写入 `crm_lead`

---

```
POST /api/customer/chat
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| message | string | 是 | 用户消息 |

## 四、企业接口 `/api/enterprise`

所有接口需要认证（EMPLOYEE 或 ADMIN）。

### 4.1 意向客户管理 (CRM)

```
POST   /api/enterprise/lead          # 录入新客户
GET    /api/enterprise/lead?status=  # 查询客户列表（支持按状态筛选）
PUT    /api/enterprise/lead/{id}     # 更新客户信息
```

### 4.2 员工日报

```
POST   /api/enterprise/report                    # 提交日报
GET    /api/enterprise/report?employee_id=       # 查询日报
```

### 4.3 学生成绩

```
POST   /api/enterprise/score                     # 录入单条成绩
GET    /api/enterprise/score?student_id=         # 查询学生成绩
POST   /api/enterprise/score/batch               # 批量上传（Excel/CSV）
```

### 4.4 员工管理

```
GET    /api/enterprise/employee                  # 查询员工列表
PUT    /api/enterprise/employee/{id}             # 修改员工信息
```

### 4.5 课程项目管理

```
POST   /api/enterprise/project                   # 添加项目
DELETE /api/enterprise/project/{id}              # 删除项目（仅 ADMIN）
```

### 4.6 仪表盘

```
GET    /api/enterprise/dashboard
```

响应：
```json
{
  "lead_total": 7, "lead_new_this_month": 3,
  "student_total": 2, "active_events": 6,
  "pending_tickets": 2, "pending_leaves": 2,
  "high_risk_alerts": 1
}
```

### 4.7 审批管理（班主任）

```
GET    /api/enterprise/approvals/pending                  # 名下学生待审批列表
POST   /api/enterprise/approvals/{id}/approve             # 审批（同意/驳回）
```

body: `{"approved": true, "reject_reason": "理由不充分"}`

审批通过/驳回后自动创建通知给对应学生。

### 4.8 组织架构

```
GET    /api/enterprise/org-chart                         # 组织架构树
GET    /api/enterprise/org-chart/department?dept_name=   # 按部门查成员
```

### 4.9 企业助手对话 / NL2SQL

```
POST   /api/enterprise/chat              # 企业助手对话
POST   /api/enterprise/nl2sql            # 自然语言查询
POST   /api/enterprise/nl2sql/update     # 自然语言更新（安全白名单）
POST   /api/enterprise/voice-report      # 口述 → 结构化日报
```

## 五、学生接口 `/api/student`

### 5.1 学生信息

```
GET    /api/student/info?student_id=     # 查询学生基本信息（仅查自己）
```

### 5.2 请假

```
POST   /api/student/leave                # 提交请假申请（仅 STUDENT）
GET    /api/student/leave?student_id=    # 查询请假记录
```

提交请假时自动预填班主任为审批人，返回班主任联系信息。

### 5.3 投诉反馈

```
POST   /api/student/feedback             # 提交反馈工单（仅 STUDENT）
GET    /api/student/feedback?student_id= # 查询反馈列表
PUT    /api/student/feedback/{id}/resolve # 处理工单（仅 EMPLOYEE/ADMIN）
```

提交时自动通知管理员和班主任，并给学生发送确认通知。

### 5.4 心理预警

```
POST   /api/student/psych-alert          # 提交预警（仅 STUDENT）
GET    /api/student/psych-alert?risk_level= # 查询预警列表（仅 EMPLOYEE/ADMIN）
```

### 5.5 学业考务

```
GET    /api/student/academic?student_id=&academic_type=  # 教务列表
GET    /api/student/academic/upcoming?student_id=&days=14 # 即将到期DDL
```

### 5.6 留学进度

```
GET    /api/student/study-abroad?student_id=      # 全流程进度
GET    /api/student/study-abroad/current?student_id= # 当前所处阶段
PUT    /api/student/study-abroad/{id}             # 更新进度（仅 EMPLOYEE/ADMIN）
```

### 5.7 站内通知

```
GET    /api/student/notification?recipient_id=       # 通知列表
GET    /api/student/notification/unread-count?recipient_id=  # 未读数
PUT    /api/student/notification/{id}/read?recipient_id=     # 单条已读
PUT    /api/student/notification/read-all?recipient_id=      # 全部已读
```

### 5.8 学生助手对话 / NL2SQL

```
POST   /api/student/chat                 # 学生助手对话（仅 STUDENT）
POST   /api/student/nl2sql               # 自然语言查本人数据（自动限 scope）
```
