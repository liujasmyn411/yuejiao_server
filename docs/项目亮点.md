# 粤教服务 AI Agent — 五大核心工作流

## 一、统一对话入口 + LLM 意图路由 + 角色权限三层防护

**涉及文件：** [api/chat_routes.py](../api/chat_routes.py)、[utils/llm_client.py](../utils/llm_client.py)

```
POST /api/chat { message, student_id?, user_id? }
  │
  ├─ Step 0  槽位填充会话检查 → 有活跃会话则 LLM 判断"补充信息"或"新话题"
  ├─ Step 1  LLM 意图分类（customer/enterprise/student）→ 语义级别识别
  ├─ Step 2  LLM 失败 → 本地关键词兜底 _local_classify_for_role()
  ├─ Step 3  角色权限校验 _agent_allowed_for_role() → 游客不可访问 student/enterprise
  └─ Step 4  路由到对应 Agent → route_intent() → 二级意图分发
```

**核心逻辑：**

- **LLM 优先 + 关键词兜底**：[chat_routes.py:166-178](../api/chat_routes.py#L166-L178) — 先调 LLM 做语义意图分类，网络不可用时降级到本地关键词匹配
- **按角色限词**：[chat_routes.py:214-246](../api/chat_routes.py#L214-L246) — 游客只匹配客服/闲聊词，学生匹配学生/客服/闲聊词，员工匹配企业/客服/闲聊词
- **不合规自动回退**：[chat_routes.py:181-185](../api/chat_routes.py#L181-L185) — 游客尝试访问 student agent → 自动降级到 customer agent

## 二、多轮槽位填充状态机 + 三层逃生机制

**涉及文件：** [utils/conversation_state.py](../utils/conversation_state.py)、三个 Agent 的 `route_intent()` / `continue_data_collection()`

```
SlotState 状态机:
  collecting ──→ confirming ──→ done
       ↑              │
       └── 补充信息 ───┘
```

**核心逻辑：**

- **自动字段提取**：[student/agent.py:143-163](../agents/student/agent.py#L143-L163) — 请假场景：LLM 自动提取请假类型/开始时间/结束时间/原因，支持"明天""下周一"等自然语言日期
- **确认→写入闭环**：[student/agent.py:416-423](../agents/student/agent.py#L416-L423) — 用户回复「确认」→ `_commit_collected()` 自动写入数据库 + 返回工单编号
- **三层逃生防死循环**：[conversation_state.py:34-43](../utils/conversation_state.py#L34-L43)
  - 第一层：关键词检测（"查询/成绩/活动"等 → 立即释放会话）
  - 第二层：LLM 语义判断（"补充信息"还是"新话题"）
  - 第三层：交互次数兜底（超过 5 轮自动清状态）
- **必填字段驱动**：[conversation_state.py:88-109](../utils/conversation_state.py#L88-L109) — 4 张表的必填字段定义，`context` 中的字段自动跳过（如 student_id 从请求上下文注入）

## 三、NL2SQL 安全引擎：自然语言 → 安全 SQL + 学生数据隔离

**涉及文件：** [agents/enterprise/nl2sql.py](../agents/enterprise/nl2sql.py)

```
用户自然语言 → LLM 生成 SQL → 多层安全校验 → 执行 → 格式化返回
```

**核心逻辑：**

- **SELECT 安全**：[nl2sql.py:91-115](../agents/enterprise/nl2sql.py#L91-L115)
  - 单词 DML 黑名单：INSERT/DELETE/DROP/ALTER/TRUNCATE 等，用 `\b` 词边界匹配避免误杀列名（如 `delete_flag`）
  - 多词模式黑名单：`INTO OUTFILE`/`LOAD_FILE`/`SLEEP()`/`BENCHMARK()` 用子串匹配
  - 表白名单校验：FROM/JOIN 中的表必须在 11 张允许表中
- **UPDATE 安全**（更严格）：[nl2sql.py:117-150](../agents/enterprise/nl2sql.py#L117-L150)
  - 强制 WHERE + LIMIT 双条件
  - 表级白名单：仅 4 张表允许 UPDATE
  - 列级白名单：每张表只允许修改特定列（如 crm_lead 只能改 status/follow_up_history/next_follow_time/score/owner_employee_id）
- **学生数据隔离**：[nl2sql.py:202-252](../agents/enterprise/nl2sql.py#L202-L252)
  - `_apply_student_scope()` 在 WHERE 中自动注入 `student_id = N`
  - 先清理 LLM 可能生成的占位符 `student_id = ?` 和硬编码 ID
  - 仅对学生相关 5 张表生效

## 四、心理监测引擎：全消息旁路评估 + 两级检测 + 自动预警

**涉及文件：** [agents/student/psych_monitor.py](../agents/student/psych_monitor.py)、[agents/student/agent.py:62-72](../agents/student/agent.py#L62-L72)

```
用户消息 → route_intent() 处理
              │
              └─ 所有意图（心理关怀除外）都走旁路心理评估
                   ├─ 本地关键词快速检测 → 命中高危词直接返回 high
                   ├─ LLM 深度评估 → 情绪标签 + 评分 + 风险等级
                   └─ should_alert() → high/medium 自动写预警表 + 更新心理画像
```

**核心逻辑：**

- **两级评估**：[psych_monitor.py:34-58](../agents/student/psych_monitor.py#L34-L58)
  - 第一级：本地关键词快速检测（19 个高危词 + 29 个中危词），毫秒级响应
  - 第二级：LLM 深度评估，返回结构化结果 `{emotion_tag, emotion_score, risk_level, trigger_reason}`
- **全消息覆盖**：[student/agent.py:64-72](../agents/student/agent.py#L64-L72) — 心理关怀之外的 8 种意图全部做轻量评估，截图不遗漏
- **风险分级回复**：[psych_monitor.py:85-103](../agents/student/psych_monitor.py#L85-L103) — high/medium/low/none 四档不同语气的回复指导
- **自动记录**：[student/agent.py:886-924](../agents/student/agent.py#L886-L924) — 触发预警自动写入 `student_psych_alert` + 更新 `student_psych_profile`（累计风险次数）

## 五、客户画像研判 + 自动转化引擎：双项目评分 → 自动录入 CRM

**涉及文件：** [utils/file_parser.py:182-363](../utils/file_parser.py#L182-L363)、[agents/enterprise/agent.py:256-371](../agents/enterprise/agent.py#L256-L371)、[agents/customer_service/agent.py:153-168](../agents/customer_service/agent.py#L153-L168)

```
对话输入 或 文件上传(PDF/Excel)
  │
  ├─ LLM 提取结构化画像 {姓名, 年龄, 学历, 意向国家, 语言水平, 家庭经济, ...}
  │
  ├─ assess_lead_intention() 双项目评分
  │   ├─ 新加坡项目：年龄区间 + 学历匹配 + 家庭经济 + 意向国家 = 加分
  │   └─ 德国项目：18-35岁 + 学历高中以上 + 德语/英语 + 动手能力 = 加分
  │
  └─ 评分 ≥ 50 且 matched → 自动写入 crm_lead（状态"新增意向"）
```

**核心逻辑：**

- **双通道入口**：
  - 对话研判：[enterprise/agent.py:256-371](../agents/enterprise/agent.py#L256-L371) — LLM 提取画像 → `assess_lead_intention()` 评分 → 自动录入
  - 文件解析：[file_parser.py:10-82](../utils/file_parser.py#L10-L82) — PDF/Excel/TXT 解析 → 正则提取画像字段 → 研判 → 录入
- **统一研判函数** `assess_lead_intention()`：[file_parser.py:182-363](../utils/file_parser.py#L182-L363)
  - 新加坡项目：14-16岁→初中项目(+30)、17-19岁→高中项目(+30)、学历加分(+15~25)、家庭经济(+5~10)
  - 德国项目：18-35岁(+25)、学历高中以上(+20)、德语(+15)/英语(+5)、动手能力(+10)
  - 意向国家明确时自动排除另一个项目的评分
  - 阈值 50 分，达标即判定为意向客户
- **自动转化**：判定通过 → 直接写入 `crm_lead` 表，渠道标记为 `AI对话-画像研判` 或 `文件解析`，无需人工介入
