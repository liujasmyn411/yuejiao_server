# 粤教服务 AI Agent 系统 — 数据库设计

## 概述

数据库名称：`yuejiao`  
字符集：`utf8mb4` — 存储引擎：`InnoDB`  
共 15 张表，覆盖用户体系、CRM、教务、留学进度、活动管理、心理关怀、通知、组织架构。

所有表均采用 `delete_flag`（软删除）+ `create_time` / `update_time`（时间戳）规范。

---

## 一、用户与权限

### 1. sys_user — 统一用户表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| username | VARCHAR(50) UNIQUE | 登录账号 |
| password_hash | VARCHAR(255) | bcrypt 加密密码 |
| real_name | VARCHAR(30) | 真实姓名 |
| user_type | VARCHAR(20) | `ADMIN` / `STUDENT` / `EMPLOYEE` |
| employee_role | VARCHAR(50) | 员工角色（班主任/市场专员/教务主管/留学顾问/客服专员） |
| head_teacher_id | BIGINT | 班主任ID（学生必填，关联 sys_user.id，该用户须为 EMPLOYEE + 班主任角色） |
| department | VARCHAR(100) | 部门/院系 |
| contact_info | VARCHAR(20) | 手机号 |
| email | VARCHAR(100) | 邮箱 |
| id_card | VARCHAR(30) | 身份证 |
| avatar | VARCHAR(255) | 头像URL |
| country_region | VARCHAR(30) | 国家/地区（默认"中国"） |
| status | VARCHAR(20) | 账号状态（正常/禁用） |
| last_login_time | DATETIME | 最后登录时间 |
| last_login_ip | VARCHAR(50) | 最后登录IP |

**关系链：** 学生 → `head_teacher_id` → 班主任（EMPLOYEE），用于请假审批路由。

## 实体关系概览

```
sys_user (统一用户)
  ├── 1:N → student_admin_service (请假)
  ├── 1:N → student_psych_alert (心理预警)
  ├── 1:1 → student_psych_profile (心理画像)
  ├── 1:N → student_feedback_ticket (反馈工单)
  ├── 1:N → student_score (成绩)
  ├── 1:N → student_academic (教务DDL)
  ├── 1:N → student_study_abroad_progress (留学进度)
  ├── 1:N → crm_lead (归属客户) [as EMPLOYEE]
  ├── 1:N → employee_daily_report (日报) [as EMPLOYEE]
  └── 1:N → notification (通知)

event_lecture (活动)
  └── 1:N → event_registration (报名)

org_department (组织架构)
  └── 自引用 parent_id 形成树形结构
```
